# AI tool logos: sources

The logos on AI, Coding and Robotics for Students (AI Tools Students Explore). Each is the
tool's own mark, taken from the SVG on Wikimedia (Commons, or English Wikipedia for Canva),
where the file is listed as public domain or CC0 because it is a simple logo. Copyright
status aside, every name and logo is a trademark of its owner; the page says so under the
cards and uses them only to name the tools students work with. Replace any of them from the
studio (AI, Coding and Robotics for Students > Tool cards), for example with a file from the
owner's own press kit.

Where a file combined the symbol and the wordmark, only the symbol was kept (noted below).
The Midjourney file had no viewBox, so one was added to frame the emblem. Nothing else was
changed. All files were checked for scripts and external links (there are none).
