# AI tool logos: sources

The logos on the AI tool cards (AI, Coding and Robotics for Students; AI for Professionals &
Educators). Each is the tool's own mark. Most are the SVG on Wikimedia Commons, where the file
is listed as public domain or CC0 because it is a simple logo; the rest come from the company
itself (its brand page, press kit or the icon its website serves), as noted. Copyright status aside, every name and logo is a trademark of its owner; the
pages say so under the cards and use them only to name the tools taught. Replace any of them from
the studio (the programme's Tool cards), for example with a file from the owner's own press kit.

Where a file combined the symbol and the wordmark, only the symbol was kept (noted below).
The Midjourney file had no viewBox, so one was added to frame the emblem. Nothing else was
changed. All files were checked for scripts and external links (there are none).
